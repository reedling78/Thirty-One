# Claude Design canvas — source snapshot

Source files of the ThirtyOne design canvas: https://claude.ai/artifact/LACRZUeD3uPc36K4BCnXW9

Snapshot of artifact version `1791863014-c1bc`, pulled 2026-10-13. `canvas.json` is the board layout (positions, titles, section headings); each `*.dc.html` is one artboard. They render only inside the Claude Design canvas (they load its runtime via `support.js`, which is not included), so treat them as the editable source, not as viewable pages.

The canvas is where the design is edited. When it changes, re-pull these files and commit them with the matching note in [[Design]] and any change to `apps/mobile/src/theme/`.
